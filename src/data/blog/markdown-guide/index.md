Markdown 是一种轻量级标记语言，让你专注于写作本身。这篇指南介绍常用的 Markdown 语法。

## 基本语法

### 标题

使用 `#` 号表示标题，最多支持六级：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

### 强调

- **加粗**：用两个星号包裹 `**加粗**`
- *斜体*：用一个星号包裹 `*斜体*`
- ~~删除线~~：用两个波浪线包裹 `~~删除线~~`

### 列表

无序列表用 `-` 或 `*`：

- 列表项一
- 列表项二
  - 嵌套项

有序列表用数字：

1. 第一项
2. 第二项
3. 第三项

## 代码

行内代码用反引号包裹：`const x = 1`

代码块用三个反引号：

```javascript
function greet(name) {
  console.log(`Hello, ${name}!`);
}
```

## 总结

Markdown 语法简洁，只需记住几个常用标记即可开始写作。多写多练，自然熟练。
