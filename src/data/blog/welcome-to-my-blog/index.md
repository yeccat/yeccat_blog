欢迎来到我的个人博客！这是第一篇文章，记录这个博客的诞生。

## 为什么建这个博客

我想要一个属于自己的空间，记录技术学习、项目经验和生活感悟。市面上有很多博客平台，但我希望拥有完整的控制权——从内容到样式，从数据到部署。

## 技术选型

这个博客使用以下技术栈构建：

- **Astro** — 静态站点生成器，专为内容站点设计，加载极快
- **Tailwind CSS** — 原子化 CSS 框架，响应式设计开箱即用
- **Markdown** — 文章以纯文本编写，Git 管理版本

### 为什么选 Astro

Astro 默认输出零 JavaScript 的静态 HTML，这意味着：

1. 页面加载速度极快，用户体验好
2. 搜索引擎能完美抓取内容，SEO 友好
3. 部署简单，纯静态文件可放在任意托管平台
